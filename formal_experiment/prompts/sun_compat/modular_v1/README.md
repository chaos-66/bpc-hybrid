# Direct-LLM modular prompt v1

This directory is the source of truth for the simplified Direct-LLM prompt
used by the E/S/J factorial follow-up.  It does not replace the historical v6
prompt or the frozen `ablation_v2` arms.

## Common part

`common_system.md` + `user_envelope.md`: minimum task, source envelope, field
names, fixed method/validation values, and the required top-level interface.
No semantic rule, example, or output-discipline text is duplicated here.

## Switchable modules

| Module | File | Unique responsibility |
|---|---|---|
| S | `semantic_rules_S.md` | Semantic interpretation: element definitions, scope, ambiguity, clause/coordination/relation rules. |
| E | `examples_E.md` | Synthetic worked examples that apply the semantic rules; no restatement of the rules and no serialization tutorial. |
| J | `output_format_J.md` | Serialization discipline only: bare JSON object, no wrapper/prose, no empty-record refusal. |

## Combination code

`ESJ`, in that order:

- `E=1`: include `examples_E.md` in the user prompt.
- `S=1`: include `semantic_rules_S.md` in the system prompt.
- `J=1`: include `output_format_J.md` in the system prompt.

`generated/` contains the eight rendered prompt files and their manifest.
They are generated by `scripts/build_modular_prompt_v1.py` and are loadable by
`bpc_hybrid.prompt_loader` as `modular_v1/generated/<stem>`.
