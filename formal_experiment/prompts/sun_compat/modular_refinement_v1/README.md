# Direct-LLM targeted refinement prompt v1

This directory owns the SEP-C3 failure-driven targeted-refinement prompt family.
It does not replace the frozen `modular_v1` E/S/J family or the historical v6
prompt.

## Source modules

- `../modular_v1/common_system.md` and `../modular_v1/user_envelope.md`:
  reused byte-for-byte as the common skeleton.
- `../modular_v1/examples_E.md`: reused byte-for-byte as the E module.
- `R_A_actor_minimality.md`: frozen R_A wording.
- `R_C_constraint_recall.md`: frozen R_C wording.

The composer is `src/bpc_hybrid/modular_refinement_prompt.py`.  Repairs are
appended as independent system-prompt paragraphs after the common skeleton.
The user envelope and E block are never modified.

## Arms

| Arm | Composition |
|---|---|
| A | common + E (exact `100` baseline) |
| B | common + E + R_A |
| C | common + E + R_C |
| D | common + E + R_A + R_C |

No arm includes S or J.

## Generated prompts

`generated/` contains the four rendered prompt files and `manifest.json`.
They are generated by `scripts/build_sep_c3_targeted_refinement_v1.py --write`
and loaded as `modular_refinement_v1/generated/<stem>`.

The Phase-1 zero-network checks are:

```powershell
python formal_experiment/scripts/build_sep_c3_targeted_refinement_v1.py --write --overwrite --check
python formal_experiment/scripts/prepare_sep_c3_targeted_refinement_v1.py --prepare --overwrite --check
python formal_experiment/scripts/run_sep_c3_targeted_refinement_v1.py --check
```

Real calls additionally require `--execute --allow-llm` and the prepared
budget/schedule contract.  The runner interleaves arms at sample level using
the saved schedule.
