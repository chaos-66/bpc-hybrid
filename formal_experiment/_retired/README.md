# 退役材料归档区

本目录保存已经退出活动流程、但仍有追溯价值的文件。它不是代码垃圾桶，也不是
新的活动目录。这里的文件不得被活动代码导入、不得直接作为实验输入、不得据此
启动任务。

## 使用规则

- 当前路线、状态和执行规则只从 `../docs/`、`../configs/`、`../scripts/` 和
  `../src/` 读取。
- 归档文件保持原内容，不为修测试而改写历史。
- 恢复任何归档文件到活动区前，必须得到用户明确批准，并在
  `../docs/EXPERIMENT_LOG.md` 与 `../docs/EXPERIMENT_EVENTS.jsonl` 追加事件。
- 根目录的 `references/` 和 `archive/` 仍是只读来源库；本目录不替代它们。
- 完整迁移清单、原路径和归档理由见 `MANIFEST.md`。
